# Dynamic-TSP-via-Dynamic-Programming
Finding the solution to the Travelling Salesman Problem (TSP) in our project is oriented to finding the way to plan efficient delivery routes. We are faced with the problem of finding the shortest route such that our system can go to each of the necessary destinations once. When we started looking at the problem, it became apparent that the number of possible routes increases rapidly and that it is hard to provide a manual computation of a good route. This complicated nature raised a big concern to us, notably due to the fact that delivery operations should be time efficient and cost effective. To solve this, we investigated algorithms and approaches that have the capability of producing near-optimal routes without excessive processing time.
We are tasked to design an algorithm that allows us to plan a delivery route, where Alice must pick up packages from warehouses (limited capacity per warehouse), visit clients to deliver packages, and complete the entire route within a strict time limit. The objective is to maximize the total packages delivered.
