# Dynamic-TSP-via-Dynamic-Programming
Finding the solution to the Travelling Salesman Problem (TSP) in our project is oriented toward planning efficient delivery routes. We are tasked to design an algorithm where packages must be picked up from warehouses, delivered to clients within a strict time limit, and maximize total packages delivered. Because manual computation is difficult and the number of possible routes increases rapidly, we investigated advanced optimization approaches. While the baseline Ant Colony System provides a foundation, it frequently suffers from premature convergence and gets trapped in local minima. To address these limitations, we enhanced the algorithm by introducing a genetic mutation operator that actively detects stagnation and escapes local traps. Furthermore, we revised the global update rule to allow the top-$l$ best ants to simultaneously update the pheromone matrix rather than relying on a single best ant. Through these targeted improvements, our enhanced algorithm achieved a 2.54x speedup in wall-clock execution time down to 156.03 seconds. It also successfully converged in 6,909 iterations compared to the baseline's 8,147 iterations. Finally, it improved the optimal solution cost to 121, providing a superior and more efficient approach for our delivery routing needs.
